# Write the handoff

1. Start with the outcome: complete, partly complete, blocked, or not started.
2. Explain what changed in terms of behavior, not only file names.
3. Include the actual diff, or the exact command and comparison that shows it.
4. List checks that passed, checks that failed, and checks that did not run.
5. State risks, known limits, decisions still needed, and the recommended next step.
6. Use `$ste100` for the explanatory text when that skill is installed. Preserve code, commands, paths, diffs, and raw error output exactly.
7. If `$ste100` is not installed, say that a formal STE100 check was not run. Still write in short, direct English.

Do not say the work is done unless the evidence supports it. Do not claim formal STE100 compliance unless the installed skill completed its checks.
