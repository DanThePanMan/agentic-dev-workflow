# Check the user experience

1. Read the expected behavior and any design reference.
2. Check normal, loading, empty, error, disabled, and success states when they apply.
3. Check keyboard use, focus, labels, readable contrast, meaningful feedback, and narrow and wide screens.
4. Check that content, layout, and interactions match the requested behavior.
5. Run available browser or component checks. Use screenshots when they help prove a visual result.
6. Report problems with steps to reproduce and a clear priority.

Automated checks help, but they do not replace a manual check of important user paths.
