# Create or improve a skill

1. Confirm that a skill is the right answer. A project note, template, or small script may be better.
2. Write a short name and description that say what the skill does and when to use it.
3. Write only the instructions that improve decisions or prevent a real mistake.
4. Use normal English. Explain needed technical terms. Do not hide meaning behind AI-style labels.
5. Add files only when the skill needs them. Keep scripts safe and test them.
6. Test the skill on a realistic request and a nearby request where it should not apply.
7. Record where outside ideas or files came from, their licence, and what was changed.

Do not copy unreviewed third-party instructions or change shared settings without approval.
