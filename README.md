# Personal Development Skills Kit

Concise skills for planning and building software with Codex.

## Use

The skills are in `.agents/skills/`. Codex can select them when they match your request, or you can name one directly, for example: `$implementation-plan`.

## Skills

- `repository-orientation` - understand an unfamiliar repository.
- `decision-support` - compare choices before you commit.
- `grill-requirements` - clarify what you want before work begins.
- `specification` - write a clear description of the desired behavior.
- `implementation-plan` - research the relevant code and write the plan for the work.
- `test-first-implementation` - build and prove one planned change at a time.
- `git-workflow` - prepare safe, focused commits.
- `debugging` - reproduce a problem, find its cause, and prevent it returning.
- `code-review` - review the actual changed lines.
- `security-review` - check changes that affect safety-sensitive code or data.
- `frontend-quality` - check user-facing changes.
- `delivery-and-handoff` - report the result in plain English.
- `retrospective` - suggest improvements after completed work.
- `case-study` - save reusable lessons from substantial work.
- `skill-authoring` - add or improve a skill safely.

## STE100

`delivery-and-handoff` uses `$ste100` when it is installed. The STE100 source reviewed for this kit is archived and does not provide a normal redistribution licence, so it is not copied here. Install it separately before relying on a formal STE100 check.
